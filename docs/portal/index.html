O que não está aqui

i
O painel React e o backend não são publicados

A aplicação de verdade — frontend/ em React + Vite sobre backend/ em FastAPI — depende de uma API em execução e não funciona num site estático. Para rodá-la, use iniciar-app.bat na raiz do repositório. O painel aqui publicado é o porte 1:1 dessa tela em HTML puro, com um snapshot dos mesmos dados.

Acesso e sigilo

!
Link aberto, fora das buscas

O repositório é público, então o GitHub Pages não pede autenticação: quem tiver o endereço entra. O que existe é robots.txt e noindex em todas as páginas, o que mantém o portal fora dos buscadores. Se o conteúdo precisar de acesso controlado, o caminho é repositório privado com Pages privado (plano pago) ou outro host — não este.

Sobre os dados

  • Todo o inventário do painel é fictício, gerado por backend/app/data.py — nenhuma placa, cliente ou preço real.
  • A regra da spec vale também na demonstração: avaria nula não é zero. O veículo sem avaliação aparece como "Não avaliado", com alerta — nunca como classe A.
  • Os números dos relatórios são de execuções reais da suíte; as capturas em /evidencias/ são as daquela execução.
